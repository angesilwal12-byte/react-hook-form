# `*` Universal Selector

The `*` selector selects **all HTML elements**.

```css
* {
  margin: 0;
  padding: 0;
}
```

This applies to every element on the page.

### Common use

```css
* {
  box-sizing: border-box;
}
```

**Remember:** `*` = **all elements**
